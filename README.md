# Excel 订单管理模板

Python 自动生成的 Excel 订单管理系统，支持产品管理、客户报价、订单录入和打印输出。

## 功能特点

- **5个工作表**：产品库、客户资料、客户报价、订单录入、打印模板
- **智能录入**：
  - 产品/客户下拉选择
  - 单价自动查找（优先客户报价 → 次选产品库）
  - 订单号自动生成（相同日期+客户自动继承订单号）
  - 总价自动计算
- **打印模板**：选择订单号后自动显示该订单所有明细
- **统计汇总**：按日期/客户/产品筛选统计

## 快速开始

### 1. 安装依赖

```bash
pip install openpyxl
```

### 2. 运行程序

```bash
python create_excel.py
```

运行后会在桌面生成 `订单打印模板.xlsx`

### 3. 使用说明

#### 产品库（Sheet 1）
- 维护产品名称、规格、单位、单价
- 示例：焦糖瓜子、奶油瓜子 等

#### 客户资料（Sheet 2）
- 维护客户名称、联系人、电话、地址

#### 客户报价（Sheet 3）
- 设置不同客户对不同产品的报价
- 优先级高于产品库单价

#### 订单录入（Sheet 4）
- **日期**：输入 `2026/02/19` 格式
- **客户/产品/规格**：下拉选择
- **单价**：自动带出（客户报价 → 产品库）
- **数量/重量**：手动输入，总价自动计算
- **订单号**：日期+客户相同则自动继承上一行订单号
- **打印状态**：下拉选择"未打印"/"已打印"

#### 打印模板（Sheet 5）
- 在 B5 单元格选择订单号
- 自动显示该订单所有产品明细
- 显示合计金额

#### 统计汇总（Sheet 6）
- 设置日期范围、客户、产品筛选条件
- 自动计算总金额和订单数量

## 数据配置

修改 `data_config.py` 文件调整测试数据：

```python
# 产品库
SAMPLE_PRODUCTS = [
    ["产品名称", "规格", "单位", 单价, "备注"],
]

# 客户资料
SAMPLE_CUSTOMERS = [
    ["客户名称", "联系人", "电话", "地址", "备注"],
]

# 客户报价
SAMPLE_CUSTOMER_PRICES = [
    ["客户名称", "产品名称", "规格", 单价],
]

# 订单数据
SAMPLE_ORDERS = [
    ["日期", "客户", "产品名称", "规格", 数量, "订单号", "打印状态"],
]
```

## 技术栈

- Python 3
- openpyxl - Excel 操作库

## 注意事项

- WPS 可能不完全支持数组公式，打印模板建议使用 Microsoft Excel
- 订单号自动生成依赖日期和客户，修改这两列会自动更新订单号
- 打印模板支持显示同一订单号的多行产品明细
